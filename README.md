# Same-Isotope Cooling Data

## Description
This project is designed to accompany the following paper: https://arxiv.org/pdf/2605.27577.

The data used to plot the experimental results in the main text of the paper are provided in the "Raw Data" Folder, with the corresponding figures in the "Figures" folder.
